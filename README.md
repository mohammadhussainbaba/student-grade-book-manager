# Student Grade Book Manager

A C-based application for storing and analyzing student academic marks.

## 📌 Project Overview

The Student Grade Book Manager is a C programming project that manages student records and analyzes their marks.

The project demonstrates fundamental programming and Data Structures and Algorithms concepts using arrays, structures, loops, conditional statements, and string processing.

## ✨ Features

- Add student records
- Store student names and marks
- Display student records
- Find the highest mark
- Find the lowest mark
- Calculate class average
- Count passing students
- Display complete grade analysis

## 🛠️ Technologies Used

- C Programming
- Arrays
- Structures
- String Processing
- Loops
- Conditional Statements
- Basic Algorithms

## ✅ Passing Criteria

Students who score **50 or above** are considered passing.
